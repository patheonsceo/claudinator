# Claudinator 1.0.0 "Complete": how it was built

- **Spec:** `docs/design/2026-10-03-claudinator-design.md` (milestones 0.2 to 1.0, delivered together)
- **Starting point:** 0.1.0 (Hairline, four ingredients, the picker, themes, CI)

The remaining milestones were built in one release instead of five, in three workstreams that shared one contract.

## 1. The contract (built first, by hand)

- `types/index.d.ts` and `src/engine/settings.ts`: seven looks and Off, nine ingredients, per-look default ingredients, and the precedence (built-in defaults, look defaults, `/config` options, project file, the user's own choices). A project file can never turn on an ingredient that hides rows, directly or through a look's defaults.
- `src/looks/look.ts`: the `Look` interface, extended with `headline`, notes and a time strip on `receipt`, `band`, and `paneStyle`, plus row fields for turn offsets and edit callouts.
- `src/looks/common.ts`: shared helpers for footnotes, the time strip, -inator mode and the attention band.
- Hairline updated to the new interface as the reference implementation.

## 2. Six looks, in parallel

Each look (Broadsheet, Mission Control, Prism, Sumi, Blueprint, Thermal) was built in its own git worktree against the contract, from a written brief with the platform rules, file ownership and quality bar. Each builder:

- wrote its tests first (at least fourteen per look, covering every member, hostile input, the desktop surface, narrow terminals, fades and -inator mode),
- added its palette, generating its Claude Code theme and terminal color schemes,
- checked the look live in a real Claude Code session before committing.

Looks were merged one commit at a time and registered after the shared every-look test passed for them.

Thermal was then cut on review: next to the other five it did not earn its place. Its code, palette, themes and recordings were removed, Off moved to key `7`, and its share-code prefix `TH` is retired.

## 3. Integration (built by hand, test first)

- `src/engine/session-model.ts`: turns with prompts and titles, footnote numbering tied to the reply each call follows, per-file changes, tool time against waiting time, the file ledger, and the call waiting on the user.
- `hooks/register.ts`: footnote marks on replies, headlines above prompts, receipts with notes and the time strip, the band, the attention ladder, the panes, `/look` combos and share codes, and the picker.
- `src/panes/navigator.ts`, `src/engine/combos.ts`, `src/engine/share-code.ts`, `src/engine/attention.ts`.
- `tools/tapes.mjs`: every demo recording generated from one list, each look in its own colors.

## Quality gates

- **Tests:** every module test first; an every-look test draws each site on the terminal and desktop surfaces and fails on a refused tree, an escape code, or a desktop `Raster`.
- **Static checks:** `claude plugin validate --strict` on the marketplace and the plugin, `tsc`, and the theme and tape generators' `--check`.
- **Live sessions:** every look, plus footnotes, headlines, the time strip and the attention ladder in a real permission prompt.
- **Security review:** automated security review on every commit. Findings fixed test-first: a project's look bringing hidden rows, unsanitized paths in two looks (then sanitized centrally), and notification text reaching a script.
- **Final review:** an independent whole-branch review before release, with each Critical and Important finding fixed test-first.
