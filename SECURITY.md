# Security policy

Claudinator runs inside Claude Code with your permissions, so we treat security reports seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**[Report a vulnerability](https://github.com/patheonsceo/claudinator/security/advisories/new)**.

Do not open a public issue for a security problem. Include what you found, how to reproduce it, and the Claudinator and Claude Code versions you used.

You can expect an acknowledgement within 3 working days and a status update within 10. Once a fix ships, we credit you in the release notes unless you would rather stay anonymous.

## Supported versions

Only the latest released version receives security fixes.

## Scope

Claudinator makes no network requests and does not read Claude's history files. A report that shows it doing either, or reading or keeping more session data than a feature needs, is in scope and treated as a vulnerability.
